# Unsplash image guide
Use this file as the image sourcing brief. Every article has five image slots. The URLs are Unsplash search URLs chosen around the exact context of the source text. Open the search URL, choose a suitable photo, verify that the selected photo's license is appropriate for MindState's intended use, and record the final photo URL and photographer credit in the CMS.

## Required layout for every article
1. **Featured image:** full-width or hero image above the article body.
2. **Two-image row:** place both images immediately after the first specified source paragraph.
3. **Two-image row:** place both images immediately after the second specified source paragraph.

Never place an image inside a paragraph. Insert it only after the specified paragraph has fully ended.
